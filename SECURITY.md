# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please do not open a public issue. Email **info@ligatrix.com** with:

- a description of the issue and its impact;
- the steps or a minimal bundle that reproduces it;
- the version of the kit and of Node.js you used;
- any suggested fix, if you have one.

We acknowledge every report within 2 business days, keep you informed while we work on a fix, and credit you in the release
notes if you wish.
